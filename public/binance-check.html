Binance connection check

Run a read-only account handshake to verify that the API key stored in Render is accepted by Binance.

Authenticate the connector

Use the value you set as FINPILOT_BINANCE_CONNECTOR_TOKEN in Render. This page sends it only to FinPilot over HTTPS, does not store it, and clears the field after the request. Never enter your Binance API secret here.

Read-only verification only. This check does not place orders, transfer funds, or enable trading. Connection status is not financial advice.

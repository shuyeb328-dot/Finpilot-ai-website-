# FinPilot AI 2.4

FinPilot AI 2.4 is the Intelligence & Simulation Engine release built on the 2.3 Financial Brain.

### New
- Deterministic What-If engine
- Seven scenario classes
- Liquidity/runway analysis
- Net-worth impact
- Goal coverage
- Debt pressure
- Risk scoring
- Upside/downside envelopes
- Simulation history and evidence entries
- Backend `/api/simulate` endpoint
- Offline-first operation; AI is optional

### Run
```bash
npm start
```
Then open the displayed local URL.

### Environment
Copy `server/.env.example` if using the optional AI gateway. The simulation engine does not require it.

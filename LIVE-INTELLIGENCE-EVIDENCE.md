# FinPilot AI 2.5 — Live Intelligence & Evidence Layer

## Evidence model
Every important finding can carry:
- source
- claim
- confidence
- source type
- URL when available
- freshness state
- timestamp

## Current source registry
- SEBI Investor — investor education/protection
- Income Tax Department — tax/filing/compliance
- RBI — banking/rates/monetary policy

These are official-source starting points, not a substitute for professional advice.

## Live search
The website can open current web results without requiring a browser API key. Search queries can be recorded in the Evidence Ledger with lower confidence until independently verified.

## Contradictions
The decision layer treats stale or uncertain evidence as a reason to lower confidence and require verification rather than inventing a resolution.

## Safety
Market-sensitive, tax-sensitive and high-impact decisions should be verified against current authoritative sources before execution. The offline engine does not invent live prices or current tax rules.

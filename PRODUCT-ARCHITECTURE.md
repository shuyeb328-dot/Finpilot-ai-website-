# FinPilot AI — Website-first product architecture

The website is the primary product surface. The Android shell can later become a thin client to the same engine.

## Product loop
DATA → EVIDENCE → THESIS → VALUATION → SIMULATION → PROBABILITY → RISK → RED TEAM → ROUND TABLE → CEO/JUDGE → APPROVAL → MONITORING → OUTCOME → LEARNING

## Included product areas
Financial Brain; 10 agents; Orchestrator; Round Table Assist; CEO/Judge; Action Center; monitoring; memory; internet search; transactions; budgets; recurring bills architecture; goals; emergency fund; debt; investments; tax; security; business; assets; What-If Lab; health; cloud vault; import/export; offline decision engine; optional real AI gateway.

## Safety
The browser never receives an LLM secret. High-impact financial actions are approval-gated. Live market claims require provider evidence.

# FinPilot AI 1.9 — Free Agent Fleet

This build adds a virtual Agent Factory. Agents are internal software workers, not separate email accounts.

## Included
- 10 built-in finance agents
- Create custom virtual agents
- Enable/pause custom agents
- Run one agent or the whole fleet
- Local fleet scheduler while the website is open
- Shared Financial Brain
- Agent run history
- Existing Round Table, Action Center, memory, search and AI gateway

## Cost model
The fleet itself does not require separate email accounts or paid AI accounts. Local/deterministic runs use the browser's JavaScript engine. Optional live AI remains a separate gateway and should keep provider credentials on the server.

## Important
This scheduler runs while the website is open. A true background server scheduler can be added later when hosting is available.

# FinPilot AI 2.5

Adds the Live Intelligence & Evidence Layer to 2.4.

### Added
- Evidence Ledger view
- Official-source registry for SEBI, Income Tax Department and RBI
- Freshness tracking
- Confidence tracking
- Source URLs
- Search-query evidence capture
- Round Table stale-evidence warning
- Lower decision confidence when live evidence is stale
- Contradiction/verification policy
- Offline deterministic engine retained as fallback

### Run
```bash
npm start
```

Default: http://127.0.0.1:8787
